# P2 / P3 / P4 / P5 — implementation and how to run

## P2 — FLAN-T5 QUD generation
- Code: `src/stages/stage2_qud_generation/qud_generator.py` (`backend=t5|auto|template`)
- Default remains `template` for CPU reliability.
- Command:
```bat
python scripts\run_stage2.py --qud-backend t5
```
- First run downloads `google/flan-t5-small`. If torch/transformers fail, falls back to template and logs that fact.
- Do not claim T5 generation unless the log says `QUD generation backend: t5`.

## P3 — NLI answerability (optional blend)
- Code: `src/stages/stage3_salience/salience.py` (`use_nli=True`)
- Primary answerability remains **cosine**. NLI is an optional light blend.
- Command:
```bat
python scripts\run_stage3.py --use-nli
python scripts\run_pipeline.py data\raw\news_reuters_sample.txt --use-nli --pair-backend minilm --min-sim 0.10
```
- If CrossEncoder NLI models fail to load, cosine-only is used (logged).

## P4 — Gold attachment evaluation
- Script: `scripts/eval_gold_attachment.py`
- Compares Stage 1.5 predicted pairs to GUM gold RST edges (unordered index pairs).
- Macro precision / recall / F1 over documents. **Not** full tree UAS.
- Commands:
```bat
python scripts\eval_gold_attachment.py --max-docs 10
python scripts\eval_gold_attachment.py --split test --pair-backend minilm --min-sim 0.10
python scripts\eval_gold_attachment.py --split test --relation-backend trained
```

## P5 — Genre hold-out training
- Flag: `python scripts\train_relation_classifier.py --holdout-genres news`
- Holds out all pairs with `genre` in the list as **test**; trains on remaining genres.
- Example (news as held-out domain):
```bat
python scripts\train_relation_classifier.py --holdout-genres news --out-dir models\holdout_news
```
- GUM genres include: conversation, fiction, news, interview, academic, court, …
- Report only real metrics from the run output / `relation_eval.json`.

## Honesty
- P2/P3 success depends on local torch + model download.
- P4 is attachment of **pairs**, not projective tree matching.
- P5 is cross-genre within GUM, not external domains.
